# Tokoro OS

Tokoro OS 1.2.08 (Supra Mk3)

A JDM-themed, adaptive gaming distro built on Bazzite (Fedora Atomic) with
BlueBuild. This is the source repository that produces the signed images:

- `ghcr.io/bhattiabdullah1959-wq/tokoro-os` — AMD / Intel
- `ghcr.io/bhattiabdullah1959-wq/tokoro-os-nvidia` — NVIDIA

Set `TOKORO_NO_BANNER=1` in your shell to silence this banner.
